# Composants et provenance

Le HTML historique fourni est conservé sans altération. Il comporte une notice Three.js : « Copyright 2010-2023 Three.js Authors », SPDX-License-Identifier: MIT. Cette notice est conservée dans chaque construction.

Atkinson Hyperlegible Next est appelée par une feuille Google Fonts externe ; aucun fichier de police n'est inclus dans le dépôt ajouté ou les archives générées. Arial est la police de repli hors ligne. Les requêtes de police transmettent les informations réseau habituelles au fournisseur ; le mode hors ligne n'en dépend pas.

Les ressources 3D et médias embarqués proviennent du fichier historique. Leur inventaire de provenance et leurs autorisations de redistribution restent à documenter individuellement avant une diffusion élargie ou commerciale. Aucune licence générale nouvelle n'est attribuée aux actifs existants par ce lot.

Les scripts de test utilisent Playwright. Les workflows emploient des actions officielles GitHub dont les révisions sont fixées. Voir les fichiers de workflow et `requirements-dev.txt`.
